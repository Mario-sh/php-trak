# Projects

Store larger PHP applications here. Each project should have its own folder and README.

```text
projects/
└── project-name/
    ├── README.md
    ├── public/
    ├── src/
    ├── tests/
    ├── composer.json
    └── .env.example
```

## Project README Checklist

- Purpose and features
- Requirements and setup steps
- How to run the project
- How to run tests
- What I learned
