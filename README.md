# PHP Trak

Personal learning routine for PHP, modern PHP development, and popular PHP frameworks.

The goal of this repository is to learn by building small features every day, recording what I learn, and gradually combining the pieces into complete applications.

## Learning Goals

- Build a strong foundation in the PHP language
- Write readable, reusable, and testable code
- Understand HTTP, forms, sessions, databases, and APIs
- Learn Composer and the modern PHP ecosystem
- Build applications with Laravel and other PHP frameworks
- Practice Git, debugging, testing, security, and deployment

## Daily Routine

Each study session follows this cycle:

1. Learn one focused concept.
2. Write a small example from memory.
3. Build or improve a practical feature.
4. Test the result and fix the errors.
5. Record notes and commit the work with Git.

Suggested session:

| Activity | Time |
| --- | ---: |
| Review previous work | 10 minutes |
| Study the day's concept | 25 minutes |
| Code the exercise | 45 minutes |
| Test, debug, and document | 20 minutes |

## Roadmap

### Phase 1: PHP Fundamentals

- [ ] PHP syntax, variables, constants, and data types
- [ ] Strings, arrays, operators, and type casting
- [ ] Conditions, loops, and functions
- [ ] Include and require
- [ ] Scope, return types, and strict typing
- [ ] Object-oriented programming
- [ ] Classes, properties, methods, inheritance, and interfaces
- [ ] Exceptions and error handling
- [ ] Namespaces and autoloading

### Phase 2: Web Development with PHP

- [ ] HTTP request and response basics
- [ ] GET and POST forms
- [ ] Input validation and output escaping
- [ ] Sessions, cookies, and authentication basics
- [ ] File uploads
- [ ] Routing and reusable templates
- [ ] JSON and REST APIs
- [ ] Environment variables and configuration

### Phase 3: Databases and Tools

- [ ] SQL fundamentals
- [ ] MySQL with PDO
- [ ] CRUD operations
- [ ] Relationships, joins, indexes, and transactions
- [ ] Composer and `composer.json`
- [ ] PSR standards and coding style
- [ ] Debugging with logs and error reports
- [ ] PHPUnit and automated tests
- [ ] Git branches, pull requests, and clean commits

### Phase 4: Frameworks

- [ ] Laravel project structure
- [ ] Routes, controllers, and views
- [ ] Blade templates
- [ ] Forms, validation, and middleware
- [ ] Models and Eloquent ORM
- [ ] Migrations, factories, and seeders
- [ ] Authentication and authorization
- [ ] Queues, jobs, mail, and notifications
- [ ] API resources and automated feature tests
- [ ] Deployment and production configuration

## Project Milestones

Build projects that increase in complexity rather than only completing isolated tutorials.

1. **PHP exercises**: small programs for syntax, arrays, functions, and classes.
2. **CLI application**: a terminal-based task tracker using files or JSON.
3. **CRUD application**: a PHP and MySQL application with login and validation.
4. **REST API**: an API with authentication, database relationships, and tests.
5. **Laravel application**: a complete application with a clean UI, authorization, and deployment.

│   ├── README.md
│   └── index.php
├── Day01/
│   ├── README.md

Each day's `README.md` should contain:

- Topic and learning objective
- Key notes and examples
- Exercises completed
- Problems encountered and how they were solved
- A short reflection and next step
