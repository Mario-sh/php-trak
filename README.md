# PHP Trak

Parcours personnel pour apprendre PHP, puis Laravel, en avancant jour par jour.

## Organisation d'un jour

Chaque jour contient deux dossiers :

```text
Day00/
├── README.md
├── EX/
│   └── EX00/
│       ├── README.md
│       └── index.php
└── TP/
    └── TP01-cree-ma-premiere-page-php/
        ├── README.md
        └── index.php
```

### EX

`EX` contient les exercices courts et les petits scripts executables.

- Un dossier par exercice : `EX00`, `EX01`, `EX02`
- Un exercice se concentre sur une notion
- Le code doit rester simple et facilement testable

### TP

`TP` contient les travaux pratiques soumis avec des consignes plus completes.

- Un dossier par TP
- Le nom explique clairement le sujet
- Le `README.md` contient les consignes et l'etat d'avancement
- Le code et les fichiers necessaires restent dans le dossier du TP

## Progression

```text
Day00/
Day01/
Day02/
...
```

Quand une journee est terminee, ajouter le jour suivant et conserver la meme organisation.

## Commandes utiles

```powershell
php EX\EX00\index.php
php TP\TP01-cree-ma-premiere-page-php\index.php
```
